# Football AI Lab

Football AI Lab은 Windows 11에서 실행하고 Streamlit Community Cloud에 배포할 수
있도록 만든 한국어 축구 분석 MVP입니다. 기존 MVP 원본을 확보하지 못한 상태에서
요구사항을 기준으로 새로 구현했으므로, 원본과 동일한 코드라고 주장하지 않습니다.

> 이 앱은 통계 분석·교육용입니다. 예측 정확도나 수익률을 보장하지 않으며 자동
> 베팅·구매 기능을 제공하지 않습니다. 데모의 팀, 수치, 배당은 모두 **가상 데이터**입니다.

## 배포 주소

- Streamlit Community Cloud: <https://football-ai-lab.streamlit.app/>
- GitHub: <https://github.com/weeds1011-hash/football-ai-lab>

2026년 10월 27일 기준 저장소의 `main` 브랜치와 루트 `app.py`, Python 3.12 설정으로
배포를 검증했습니다. 배포 앱에서 가상 데모, CSV 업로드, 프로토 분석, 승무패 14경기
상위 20개 조합 계산을 직접 실행해 정상 동작을 확인했습니다.

## 구현 기능

- 여러 경기 CSV 업로드(UTF-8/CP949)와 결과 CSV 다운로드
- 독립 포아송 스코어 분포 및 Dixon–Coles 저득점 보정
- Elo 기대승률을 이용한 홈·원정 기대득점 보정
- 홈승·무승부·원정승 확률, 예상 최빈 스코어, 적정 배당
- 입력 배당 기준 기대수익률 `(모델 확률 × 배당 - 1) × 100`
- 승무패 14경기 확률표와 확률 상위 20개 조합
- 무승부 가능성 및 비우세 결과 합계가 큰 경기 표시
- football-data.org v4 실제 일정·팀·최종 결과 연동 준비
- 최근 5·10경기, 홈/원정 성적, 득실점 평균 및 순차 Elo 자동 계산
- 실제 결과 기반 모델 추정 기대득점과 표본 부족 불확실성 표시
- 갤럭시 세로 화면을 고려한 한국어 반응형 화면

## Windows 설치와 실행

권장 버전은 Python 3.12입니다. 프로젝트 폴더에서 다음 파일을 차례로 실행합니다.

```text
install_windows.cmd
run_windows.cmd
```

설치 확인과 실행을 한 번에 처리하려면 `football_ai_lab.cmd`를 더블클릭합니다.
배치파일은 8501부터 LISTEN 상태를 검사해 첫 번째 빈 포트를 자동 선택합니다. 시작
포트를 바꾸려면 `football_ai_lab.cmd 8600`처럼 지정할 수 있습니다.

브라우저에서 <http://localhost:8502>를 엽니다. 명령행에서는 다음과 같이 실행할 수
있습니다.

```powershell
uv venv --python 3.12.13 .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address localhost --server.port 8502
```

같은 Wi-Fi에 연결된 갤럭시에서 PC 앱에 접속하려면 `run_wifi_windows.cmd`를 실행한
뒤 표시된 PC IPv4 주소와 배치파일이 선택한 포트로 접속합니다. Windows 방화벽에서는
신뢰하는 개인 네트워크만 허용하세요. 외부 인터넷에 PC 포트를 직접 노출하지 마세요.
`run_windows.cmd`와 `run_wifi_windows.cmd`도 8501부터 첫 번째 빈 포트를 자동으로
선택합니다. 첫 번째 인수로 검색 시작 포트를 지정할 수 있습니다.

## CSV 형식

필수 열은 다음 네 개입니다.

| 열 | 의미 | 허용값 |
|---|---|---|
| `홈팀` | 홈 팀 이름 | 빈 문자열 제외 |
| `원정팀` | 원정 팀 이름 | 빈 문자열 제외 |
| `홈 기대득점` | 홈 기본 기대득점 | 0 초과 10 이하 |
| `원정 기대득점` | 원정 기본 기대득점 | 0 초과 10 이하 |

선택 열은 `경기번호`, `홈 Elo`, `원정 Elo`, `홈승 배당`, `무승부 배당`, `원정승 배당`,
`데이터 구분`입니다. Elo를 생략하면 1500, 배당을 생략하면 기대수익률을 빈 값으로
처리합니다. 영문 헤더 `home_team`, `away_team`, `home_xg`, `away_xg`, `home_elo`,
`away_elo`, `home_odds`, `draw_odds`, `away_odds`, `data_type`도 지원합니다.

승무패 탭에 업로드하는 파일은 정확히 14행이어야 합니다. 예시는
`data/demo_14_matches.csv`에서 확인할 수 있으며 모든 행에 `가상 데이터`가 표시되어
있습니다.

## football-data.org 실제 데이터

> Football data provided by the Football-Data.org API

실제 데이터 모드는 [football-data.org API v4](https://docs.football-data.org/general/v4/index.html)의
경기 일정, 팀 식별 정보와 최종 결과를 사용합니다. 2026년 10월 확인한
[공식 무료 플랜](https://www.football-data.org/pricing)은 12개 대회와 기본 일정·결과·순위,
분당 10회 요청을 제공합니다. 무료 제공 대회는 공식
[Coverage 페이지](https://www.football-data.org/coverage)를 기준으로 앱 선택 목록에
표시했습니다. 무료 데이터 범위와 요청 한도는 서비스 정책에 따라 바뀔 수 있습니다.

무료 플랜에 배당과 실측 xG가 포함된다고 가정하지 않습니다. 실제 데이터 모드의
`홈 기대득점`과 `원정 기대득점`은 완료 경기의 득실점으로 계산한 **모델 추정치**이며
실측 xG가 아닙니다. 배당이 없으면 기대수익률 열을 표시하지 않습니다.

로컬에서는 예시 파일을 복사해 실제 키를 입력합니다. 실제
`.streamlit/secrets.toml`은 Git에서 제외됩니다.

```powershell
Copy-Item .streamlit\secrets.toml.example .streamlit\secrets.toml
```

```toml
FOOTBALL_DATA_API_KEY = "발급받은_API_키"
```

환경변수 `FOOTBALL_DATA_API_KEY`도 지원합니다. Streamlit Community Cloud에서는 앱의
**Settings → Secrets**에 같은 TOML 항목을 저장합니다. 앱은 리그·시즌 단위 응답을
15분간 캐시해 반복 호출을 줄이며, API 429 제한·인증·응답 누락 오류를 한국어로
안내합니다. 오류가 발생해도 기존 CSV 업로드와 가상 데모는 계속 사용할 수 있습니다.

## 모델 계산 방식

1. 입력 기대득점에 홈 어드밴티지를 포함한 Elo 기대승률을 완만한 지수 배율로 적용합니다.
2. 보정된 두 기대득점으로 0~10골 포아송 스코어 결합분포를 계산합니다.
3. 0-0, 0-1, 1-0, 1-1 셀에 Dixon–Coles `rho` 보정을 적용합니다.
4. 10골 초과 꼬리를 제외한 행렬을 다시 정규화해 홈승·무승부·원정승 합계를 100%로 맞춥니다.
5. 적정 배당은 각 결과 확률의 역수로 계산합니다.

실제 데이터 모드에서는 다음 순서로 입력 전력을 만듭니다.

1. 선택한 시즌 결과 중 각 예측 경기의 킥오프보다 이른 `FINISHED` 경기만 사용합니다.
2. 팀별 최근 5·10경기 성적, 최근 10경기 평균 득점·실점과 최근 홈·원정 성적을 분리합니다.
3. 결과를 시간순으로 처리해 모든 팀을 1500에서 시작하는 Elo를 갱신합니다.
4. 리그 홈·원정 득점 평균과 팀의 최근 홈·원정 득실점을 결합합니다. 표본이 적을 때는
   리그 평균 쪽으로 수축해 과도한 값을 줄입니다.
5. 전체 경기와 해당 장소 표본 수가 적으면 불확실성을 `보통` 또는 `높음`으로 표시합니다.

선발, 결장자, 전술, 날씨, 실측 xG는 football-data.org 기본 응답에 없으므로 만들거나
추정 근거인 것처럼 표시하지 않습니다.

표시 확률은 소수 둘째 자리에서 반올림하되 최대 나머지법으로 각 경기의 세 결과 합계가
항상 100.00%가 되게 합니다.

14경기 상위 조합 계산은 모든 `3^14 = 4,782,969`개 조합을 만들지 않습니다. 각 경기
단계에서 현재 상위 20개 부분 조합만 유지하는 정확한 top-k 탐색을 사용합니다. 이후
경기의 결과 확률 집합은 모든 부분 조합에 동일하므로 같은 깊이에서 탈락한 부분 조합은
최종 상위 20개로 다시 들어올 수 없습니다. 메모리의 후보 프런티어는 최대 20개입니다.

## 모델 가정과 한계

- 입력 기대득점은 사용자가 신뢰할 수 있는 출처에서 준비해야 합니다. 앱은 xG, 선발,
  결장자, 날씨 같은 실제 정보를 만들거나 자동 수집하지 않습니다.
- 기본 포아송은 팀별 득점 독립성과 일정한 득점률을 가정합니다. Dixon–Coles는 일부
  저득점 상관만 보정하며 모든 전술·리그 특성을 설명하지 않습니다.
- Elo 보정 강도와 홈 어드밴티지는 설명 가능한 휴리스틱이며 리그별 학습·백테스트를
  거친 보정치가 아닙니다.
- 예상 스코어는 평균이 아니라 확률이 가장 큰 단일 스코어입니다.
- 기대수익률은 입력 확률과 배당의 산술 비교일 뿐 실제 우위, 수익 또는 적중률 증거가
  아닙니다. 북메이커 마진과 시장 변동도 별도로 추정하지 않습니다.
- 실제 사용 전에는 시점 분리 백테스트, 확률 보정 평가(Brier score, log loss), 데이터
  누수 점검이 필요합니다. 현재 MVP에는 검증된 예측 정확도 수치가 없습니다.

### 무승부 진단 실험

Football AI Lab의 승·무·패 예측은 베트맨 사전 투표율, 베팅 비율 및 배당률을 참고하지 않습니다. 실제 축구 경기 이력과 자체 Elo·Poisson·Dixon–Coles 모델 및 검증된 통계 지표만으로 독립적으로 계산합니다.

위 문구는 앱이 자동으로 사용하는 예측 입력과 이 실험 경로를 설명합니다. 사용자가 외부 시장 정보를 직접 기대득점이나 Elo로 변환해 CSV에 넣는 경우는 앱이 출처를 자동 검증할 수 없습니다. 기존 프로토의 배당 비교는 예측과 별도의 표시 기능입니다.

`승무패 과거검증`의 **무승부 진단 비교**에서는 기존 예측(A), 이력 보강(B), 실험적 무승부 확률(C), 보강 확률을 유지하고 후보만 표시하는 방식(D)을 구분합니다. 2026년 7~10월 연구는 가설로만 사용하며 해당 기간의 결과 및 연구 비율을 2026년 1월 예측에 넣지 않습니다. 실험 지표와 보정 모델은 아직 독립 검증되지 않았습니다.

- 입력은 기존 회차 양식과 각각 기존·보강 경기 이력 양식을 사용합니다. 허용 목록 외 열은 모두 거부하므로 투표율, 배당, 시장 예측을 넣을 수 없습니다.
- 경기 이력의 `finished_at`과 `acquired_at` 중 늦은 시각을 확인 가능 시각으로 사용하며, 그 시각이 대상 기준시각보다 엄격하게 빠른 경기만 사용합니다. 과거의 실제 정보 제공 시점을 입증하는 자료는 사용자가 확인해야 합니다.
- 2025년까지 확인 가능한 경기만으로 규제 로지스틱 모형을 학습하고, 학습 점수의 상위 사분위를 후보 표시 기준으로 씁니다. 자료가 부족하면 보정하지 않고 오류를 표시합니다. 0:0, 1:1, 2:2 확률은 경기 전 모델의 점수 행렬입니다.
- **2026년 1·2회차 재분석은 이미 결과를 확인한 데이터를 대상으로 한 사후 연구 실험입니다. 독립 검증 결과나 실제 당시 예측 성적이 아닙니다.** 2025년 학습도 제한된 표본일 수 있으며, 점수와 후보 선정은 실제 적중률이나 수익을 보장하지 않습니다.
- 연구용 로컬 경기별 보고서는 `reports/local_backtest_2026/무승부_진단_연구/`에 저장합니다. 개인용 자료와 원본 외부 자료는 Git에 포함하지 않습니다. Streamlit Cloud에는 자료를 따로 제공하지 않는 한 로컬 보고서가 나타나지 않습니다.

### 예측 시점과 데이터 충분성

- 일반 API 분석은 모든 경기에서 공통 분석 기준시각을 사용합니다. API 응답에서 `FINISHED`가 확인된 시각은 캐시된 응답을 실제로 조회한 시각이며, 정확한 경기 종료시각은 API에서 별도로 확인하지 못합니다. 조회한 시각보다 이전의 백테스트 시점에 현재 응답을 소급해 사용하지 않습니다.
- 2026 백테스트와 무승부 연구는 이력의 경기 시작, 종료 및 확보시각을 검사하고, 종료·확보 중 늦은 시각이 회차 공통 기준시각보다 이른 이력만 사용합니다. 확보시각이 없거나 순서가 잘못된 이력은 거부합니다. 사용자가 기입한 출처와 시각의 진실성이나 당시 API 원본 상태까지 자동 증명하지는 못합니다. 기존 체크포인트를 덮어쓰지 않으며 시점 필터 버전이 바뀌면 새 체크포인트를 만듭니다.
- 수동 CSV의 예상 득점·Elo 값은 생성시점이 없으면 14경기 공통 마감 전 정보인지 확인할 수 없고 엄격한 회차 시점 검증으로 간주하지 않습니다.
- API 근거표에는 기준시각, API 확인시각, 팀별 경기 수, 리그 이력의 미사용 비율, 시즌, Elo·리그 평균 기본값 사용 여부와 데이터 충분성을 표시합니다. 미사용 비율은 예정 경기 중 미종료·연기·누락 등도 포함하며 독립 검증된 누락률은 아닙니다. 현재 API 화면은 선택한 한 시즌만 조회합니다. 승격팀의 하부리그 기록을 같은 리그 이력처럼 자동 합치지 않습니다.
- 14경기 API 경로에서는 동일한 공통 분석시각을 사용합니다. 실제 회차 공통 마감시각을 확보한 과거 분석에는 회차 CSV의 마감시각을 사용합니다. CSV의 사용자 제공 숫자가 배당에서 파생됐는지는 자동 판별할 수 없습니다.
- 프로토 및 승무패 분석 후 배당과 API 키를 제외한 JSON 예측 스냅샷을 다운로드할 수 있습니다. 입력의 시점이 미확인인 경우 스냅샷에도 명시됩니다.

### 2026년 4대 리그 무승부 연구

로컬에서 수집한 2026년 7월 28일~10월 28일 EPL, 라리가, 세리에 A, 분데스리가의 **현재 확인된** 경기 결과로 리그별 무승부·스코어 분포를 계산합니다. 완료 경기 결과의 기술 통계와 과거 시점 예측의 엄격한 가용성 증명은 서로 다릅니다.

시간순 사후 비교에는 2026-01-02까지 공식 자료로 대조한 EPL 30경기와 세리에 A 66경기만 이전 이력으로 사용했습니다. 해당 시즌의 다른 경기와 2026년 경기 이력을 충분히 확보하지 못했고, 승격팀을 비롯한 일부 경기 및 라리가·분데스리가를 제외했습니다. 따라서 극도로 오래되고 불완전한 이력에 기반한 분석으로, 이미 알려진 결과를 대상으로 하므로 맹검이나 일반화 성능 검증이 아닙니다.

비교 방식은 A 기본 최고 확률 선택, B 기본 확률을 유지하면서 무승부 후보만 표시, D 고정 규칙에 따른 무승부 선택입니다. D는 무승부 확률이 최고 확률의 90% 이상이고 두 팀 Elo 차이가 50점 이하일 때 무승부를 선택합니다. 이 규칙은 실험용이며 우수성이 증명되지 않았습니다. C는 시간순으로 분리된 충분한 경기 전 학습 이력이 확보되지 않아 실제 자료에 학습·평가하지 않았습니다. `four_league_research.py`의 학습 경로는 최소 경기 수와 무승부 수를 검사하지만, 그 기준을 넘는 것만으로 통계적 신뢰성이 보장되지는 않습니다.

Elo 이력 갱신의 홈 이점은 65점으로 고정되어 있고, 화면의 홈 이점은 그 뒤 예상 득점 보정에 사용됩니다. 두 단계가 중복 보정인지 단정할 수 없어 홈 이점 0, 장소별 최근 경기 수와 리그 평균 가중치를 별도로 바꿔 사후 민감도를 비교했습니다. 자료 부족 표본의 결과로 설정을 최적화하거나 성능 향상을 주장하지 않습니다.

경기 원본과 연구 결과는 `reports/local_backtest_2026/4대리그_무승부_2026/`에 로컬 보관합니다. 사용자 승인 없이 운영 배포하거나 외부 데이터를 저장소에 공개하지 않습니다.

### 사용자 전술 자료 가상 실험

`전술 가상 실험` 탭에서 기존 프로토 또는 승무패 입력의 한 경기와 사용자 제공 팀 프로필을 선택하여 기존 확률과 **가상 시나리오**를 비교할 수 있습니다. 팀명 완전 일치만 선택 후보로 제안하며, 홈·원정 팀 연결은 사용자가 직접 확인해야 합니다. 서로 다른 리그의 팀이나 중복 팀은 거부합니다.

사용자가 제공한 7개 리그 자료는 설명의 140개가 아닌 실제 141개 팀이 포함돼 있습니다. 자료에는 수치의 출처, 측정 방법, 시즌 및 확보 시각이 없으므로 **검증되지 않은 사용자 가정**으로 취급합니다. 표기된 `xg_for_90`, `xg_against_90`은 실측 xG로 확인되지 않았으며 모델 입력에 사용하지 않습니다. 출처·시점이 검증되지 않은 선발, 결장, H2H나 2026년 이후 데이터를 과거 경기의 사실로 넣지 않습니다.

실험은 기존 기대득점에 제시된 로우 블록, 전환, 체력 가정의 배율을 적용하고 두 팀의 `draw_tendency` 및 전력 지수로 실험 rho를 계산합니다. 음수 스코어 확률을 막기 위해 rho를 제한할 수 있으며 원래 값과 적용 값을 모두 표시합니다. 기존 Elo와 홈 보정은 유지하며 프로필의 `home_adv_weight`를 중복으로 곱하지 않습니다. 이 수식의 효과는 검증되지 않았고, 결과가 높아지거나 낮아졌다는 것이 더 정확하다는 뜻은 아닙니다.

기존 예측·백테스트 및 14경기 조합에는 자동으로 반영하지 않습니다. 배당과 투표율은 이 실험의 계산에 사용하지 않습니다. 시장 정보에서 사용자가 직접 파생한 수치를 허용된 열에 넣는 경우 원천을 자동으로 판별할 수 없습니다. 실제 모델 개선 주장은 사용 허가와 경기 전 가용 시각을 확인한 시계열 자료로 학습 기간과 검증 기간을 분리해 확인해야 합니다.

제공 원본은 `data/user_tactical_profiles.csv`에 로컬로 저장하며 Git에서 제외합니다. 다른 환경에서는 같은 형식의 자료를 직접 업로드해야 합니다.

### 2026 승무패 백테스트 입력

2026년 1~63회차의 확보 현황과 로컬 배치 분석을 지원합니다. 2026-10-27 현재
베트맨 공식 결과 화면에서 63회차 14경기 결과 발표와 64회차 발매 표시를 확인했습니다.
이 결과의 앱 재사용·재배포 권한은 확인되지 않았습니다. 베트맨 및 제3자
사이트에서 자동 수집하지 않으며 사용자에게 이용 권한이 있는 자료가 필요합니다.

`2026 승무패 백테스트` 탭에서 두 CSV의 빈 양식을 다운로드할 수 있습니다.
`year, round, number`는 2026년·회차·공식 경기번호, `competition`은 이력과
같은 대회코드, 시간은 한국시간 또는 시간대 포함 ISO 형식입니다. `deadline`은
공통 마감이며 누락·불일치 시 첫 경기 1분 전과 기재된 마감 중 이른 시각을
사용합니다. 마감이 경기 시작과 같으면 1초 전으로 적용합니다. `result_status`
`정상`과 `verification` `확인`은 사용자가 출처·정규시간·홈원정·특례 여부를
검증해 직접 기입해야 합니다. 이 값은 앱이 공식 자료를 검증했다는 뜻이 아닙니다.
취소·연기·특례·미확인 회차는 계산에서 제외합니다.

이력 파일에는 팀 ID, 정규시간 스코어, 시작·결과 확정·확보시각과 출처가 모두
필요합니다. 각 회차는 기준시각 이전에 확정된 이력만 사용합니다. 팀 이름은 ID와
정규화된 완전 일치가 필요하며, 자료가 부족하면 기본 33/33/34 확률을 넣지 않고
해당 회차를 제외합니다. 기존 모델의 Elo 초기값 1500과 득점률 수축은 그대로
사용합니다. 경기 결과 수정이나 당시 정보 공개시각은 독립적으로 검증할 수 없습니다.

```powershell
# 파일이 없으면 1~63회차 미검증 현황표만 생성
.\.venv\Scripts\python.exe backtest_2026.py
# 이용 권한이 있는 CSV를 준비한 뒤 재개 (경로는 예시)
.\.venv\Scripts\python.exe backtest_2026.py --rounds C:\data\rounds.csv --history C:\data\history.csv
```

결과는 Git에서 제외된 `reports/local_backtest_2026/`에 저장됩니다. 예측은 정답
열과 분리해 회차별 체크포인트에 저장한 후 결과와 결합합니다. 재실행 시 동일
입력의 예측은 재사용하고 실패 회차는 다시 시도합니다. 체크포인트와 보고서에는
사용자 자료가 포함될 수 있으므로 공개 전 권한 및 비밀정보를 확인하세요. 현재
원래 당시 저장된 예측을 가져오는 기능, API의 과거 시점 스냅샷 검증, 투표율·배당
기준선과 수익률은 지원하지 않습니다.

이 백테스트는 현재 확보한 역사 자료로 과거를 재구성한 것이며, 과거에 실제로
저장한 예측이 아닙니다. 확정된 자료가 없는 수치는 미검증으로 표시합니다.

```powershell
.\.venv\Scripts\python.exe -m compileall -q app.py models.py test_models.py
.\.venv\Scripts\python.exe -m pytest -q
```

테스트는 확률 합계, Dixon–Coles 보정, Elo 방향성, 적정 배당·기대수익률 공식,
한국어/CP949 CSV, 14경기 가상 데이터, top-k와 소규모 전수조사의 일치, 조합 검색의
메모리 경계를 확인합니다. 실제 API는 mock 응답으로 인증 헤더·요청 한도·403·429·필수
필드 누락·점수 누락·희소 표본을 검증합니다. 예측 경기 이후 결과를 추가해도 입력 전력과
기대득점이 바뀌지 않는 회귀 테스트로 미래 정보 누수를 점검합니다.

## Streamlit Community Cloud와 비밀값

저장소의 `app.py`를 진입 파일로 선택하면 됩니다. API 키는 코드나 CSV에 저장하지 말고
Streamlit Community Cloud의 Secrets 또는 로컬 `.streamlit/secrets.toml`을 사용하세요.
`secrets.toml`은 Git에서 제외됩니다.

배포 화면의 **Advanced settings**에서 로컬 검증 버전과 같은 Python 3.12를 선택합니다.
진입 파일은 저장소 루트의 `app.py`입니다. 이 MVP는 데이터베이스를 사용하지 않으며,
업로드 CSV와 분석 결과는 서버 메모리에서만 처리합니다. Community Cloud의 재시작,
절전 또는 재배포 후에는 세션 데이터가 사라집니다. 향후 SQLite 파일을 추가하더라도
Community Cloud 로컬 디스크를 영구 저장소로 간주하면 안 됩니다.

# 2026 승무패 1~30회차 과거검증

별도의 `승무패 과거검증` 탭에서 로컬에서 검증·생성한 1~30회차 보고서를 확인할 수 있습니다. 분석 입력과 실제 결과는 분리하고, 예측 체크포인트 저장 후 평가합니다. 결과는 당시 저장된 예측이 아닌 사후 재현입니다.

검증된 로컬 체크포인트가 `reports/local_backtest_2026/`에 있을 때 `python backtest_report_1_30.py`로 보고서를 다시 생성합니다. 생성된 CSV와 보고서는 `.gitignore`로 제외되므로 Streamlit Cloud에서는 별도로 이용 권한이 확인된 자료를 제공하지 않는 한 결과가 나타나지 않습니다. 입력이 없거나 불완전한 회차는 미완료로 표시하며 통계에서 제외합니다.
